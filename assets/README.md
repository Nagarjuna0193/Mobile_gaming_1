# Assets

Place your media assets here.

- click.wav — short click/tap sound (WAV, <100ms). Update `src/utils/sound.ts` if you change the filename.
- icon.png — application icon
- splash.png — splash screen
- adaptive-icon.png — Android adaptive icon foreground
- favicon.png — web favicon

Note: The project currently tolerates missing assets; sounds will be skipped if not found. Add real images and update `app.json` to re-enable icons/splash.
